# Animation & Planning in Games (CSCI 5611)

### Graduate Academic Course | University of Minnesota
* **Language/Stack:** Processing (Java Engine), Multimedia/Video Demos
* **Core Focus:** Physically-Based Simulations, Real-Time Path Planning, and Kinematic Systems

---

### Course Overview & Scope
A highly visual codebase dedicated to real-time engineering applications within computer animation, game physics, and multi-agent spatial planning. The repository demonstrates the implementation of complex physics and spatial search algorithms engineered entirely from foundational principles without relying on black-box commercial game engines.

### Key Work Completed
* **Crowd Simulation:** Created a multi-agent navigation system utilizing Probabilistic Roadmaps (PRM) for pathfinding, ray-casting for vision, and dynamic obstacle avoidance algorithms.
* **Inverse Kinematics (IK):** Formulated and built multi-joint robotic structures (including arm, octopus, and spider profiles) calculating dynamic goal reaching.
* **Smoothed-Particle Hydrodynamics (SPH):** Implemented a real-time fluid dynamic engine simulating liquid flow, droplet dripping, and scene container boundaries.
* **Rigid Body Physics Engine:** Programmed ball-mesh collision detection, elastic collision resolutions, overlap correction logic, and a tearing cloth/mesh simulation.

### Skills & Technologies Applied
* **Physics & Kinematics:** SPH Fluid Dynamics, Inverse Kinematics, Rigid-Body Dynamics, Collision Resolution, Mesh Manipulation.
* **AI & Graph Pathfinding:** Probabilistic Roadmaps (PRM), A* / Dijkstra variants, Local Obstacle Avoidance.
* **Tooling:** Processing Graphics Library, Java bytecode compilation.
